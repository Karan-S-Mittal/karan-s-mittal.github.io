# Brand masters

Source images for the "8" mark, generated with an image model (2026-09-24). They are
not served; web versions live in `public/` and `src/components/layout/Mark.astro`.

| File | What it is |
| --- | --- |
| `symbol.png` | The 3D ribbon mark, transparent background |
| `logo-horizontal.png`, `logo-stacked.png` | Mark with name and tagline, transparent background |
| `app-icon-light.png`, `app-icon-dark.png` | App icon renders, corners baked onto white |
| `brand-guide.png` | Reference sheet: palette, sizes, mockups |
| `logo-construction.png` | Illustrative only: the mark was not built from this geometry, so don't present it as how the logo was made |

The site draws a flat two-tone vector version of the mark and keeps its own blue (`--ie-blue`),
not the sheet's #2563EB. The tagline stays in these images only.
