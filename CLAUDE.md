# Claude Code Instructions

Please refer to [AGENTS.md](./AGENTS.md) for the complete guidelines on Karan Mittal's Soft Architecture design language, visual grammar, Primary Citations verification standard, and authoring workflows.

Key Rules:
1. Tone: Engineer-scientist, mechanistic rigor, zero marketing fluff.
2. Verification: Primary citations only (arXiv papers, GitHub source lines/commits, RFCs, hardware vendor specs).
3. Visuals: Soft Architecture palette (`--ie-blue` `#2676AA` anchor, `--ie-rust` `#A63D17` constraint/failure — no separate red exists, `--ie-verified` `#157F5F` verified state, `--ie-ink` `#1A1A2E` structure), 1.5px strokes, `<Exhibit />` components. Every diagram color is a `var(--ie-*)` token — never a raw hex.
4. Docs: See `docs/design-language.md` and `docs/authoring-workflow.md`.
