# Blog Series Plan: "How Data Outgrew Every Tool We Built to Understand It"

## Overview
A 5-section + closing narrative blog (~3,500 words) tracing the evolution from human judgment → rule-based systems → ML → DL → LLMs, with each layer born from data overwhelming the previous tool.

## Structure
- Section 0: The Ledger (~400 words) - Human judgment overwhelmed by volume
- Section 1: The Age of Rules (~600 words) - Rule-based systems and their limits
- Section 2: The Geometry of Decisions (~800 words) - ML/XGBoost, feature engineering, decision boundaries
- Section 3: Teaching Machines to See (~700 words) - CNNs, representation learning, raw data
- Section 4: When the Question Itself Is the Data (~700 words) - LLMs, semantic space, reasoning
- Closing: The Hierarchy Is a Map, Not a Ladder (~300 words) - Four layers coexist

## Execution Strategy

### Stage 1: Deep Research (Parallel)
Load skill: `deep-research-swarm`
- Research agent 1: History of rule-based systems in banking/fraud detection, expert systems collapse
- Research agent 2: ML decision boundaries, XGBoost, feature engineering, tabular data dominance
- Research agent 3: CNN architecture, ImageNet 2012, representation learning, medical imaging AI
- Research agent 4: LLM architecture, transformers, semantic reasoning, LLM limitations (hallucination, precision)
- Research agent 5: The four-layer hierarchy concept — where each tool fits, coexistence evidence

### Stage 2: Writing (Serial by Section)
Load skill: `report-writing`
- Write each section sequentially with narrative continuity
- Each section gets: scene anchor, mechanism explanation, "the crack" transition
- Include visual descriptions for diagrams

### Stage 3: Review & Proofread (Parallel swarm)
- Copyeditor: Grammar, flow, consistency
- Technical reviewer: Accuracy of ML/DL/LLM technical claims
- Narrative reviewer: Story arc, scene anchors, engagement
- Final proofreader: Polish and final pass

### Stage 4: Output Formatting
- Load skill: `docx`
- Convert final markdown to formatted Word document
- Deliver final .docx

## Key Decisions
- Scenes: Keep the bank manager, fraud team, medical imaging, inventory hallucination anchors
- Depth: Intuitive + concrete numbers, metaphor-driven geometry, not full mathematical proofs
- Tone: Dense but accessible, narrative-driven technical writing
