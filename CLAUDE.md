# Claude Code Instructions

Please refer to [AGENTS.md](./AGENTS.md) for the complete guidelines on Karan Mittal's Explanatory Systems Studio design language, visual grammar, Primary Citations verification standard, and authoring workflows.

Key Rules:
1. Tone: Engineer-scientist, mechanistic rigor, zero marketing fluff.
2. Verification: Primary citations only (arXiv papers, GitHub source lines/commits, RFCs, hardware vendor specs).
3. Visuals: Explanatory Studio palette (`#2168F3` Signal, `#159A6C` Verified, `#D97706` Constraint, `#D64545` Failure, `#10213B` Ink), 1.5px strokes, `<Exhibit />` components.
4. Docs: See `docs/design-language.md` and `docs/authoring-workflow.md`.
